COLLECTION SETTINGS

采集设置

仅用于修改设置、发起采集和导入页面；不会保存在浏览器存储中。

页面适配与手动导入

网站结构变化时可配置 CSS 卡片选择器；留空自动识别。两个区域独立解析，不能互相替代。

用于服务器暂时不能访问来源时的补录，记录会明确标记为“手动导入”，不冒充自动采集。

建议 5～10 分钟一次，最短 60 秒。默认 10 分钟采样时，5 分钟图会有空缺；失败会自动退避。遇到验证或访问限制会停止本次采集。

如何读懂报价

商家回收价

你把金币卖给商家时的收购报价。按“元 / 万金”衡量，越高越好；等价的“万金 / 元”则越低越好。

玩家挂售价

你购买玩家金币时的挂单报价。按“元 / 万金”衡量，越低越好；它不是商家的收货价。

周期、采样与 K 线

周期用于聚合真实采样，开高低收来自对应时段内的报价。没有采样就留空；只有一笔时四个价格相同。图下方统计采样报价条数，不是成交量。

报价差与涨跌

仅当两侧来自同一次采集且未过期时计算价差。24 小时涨跌缺少对比点时显示“暂无对比”，不会当作 0%。报价卡片涨跌以元／万金计算；K 线按当前图表数值红涨绿跌，切换倒数单位后方向相反。
