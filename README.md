# mxd

冒险岛怀旧服「蓝色庭院2」蓝独角狮脚本。基于原先的 Windows / Python / MSS / pynput 方案，增加主画面识别、底层与顶层清怪，以及方向键加 F 瞬移。

Python 3.10–3.12，Windows 上运行游戏。Linux 可运行视觉、决策和按键模拟测试，不能直接操控 Windows 游戏。

## 已实现的行为

| 项目 | 当前逻辑 |
| --- | --- |
| 火焰箭 | D 短按，实际按下时间之间至少 0.9 秒；最后一次施法也等完整周期才移动 |
| 目标选择 | 主画面匹配蓝独角狮多姿态模板，灰度、对应位置颜色、边缘共同核对，连续两帧确认 |
| 宠物区分 | 不把小地图当成怪物雷达；宠物通过主画面的外形、颜色模板排除，需要现场观察验证 |
| 射程 | 小地图归一化 X 距离 0.086，经校准转换为主画面像素；只选脚底高度接近的同层目标 |
| 攻击次数 | 每次攻击后重新截图；通常两次可击杀，但不把两次输入当成击杀确认，目标仍在就继续攻击 |
| 巡逻 | 边走边识别，每移动 0.05 归一化 X 停下扫描；没有识别到目标时不盲打 |
| 瞬移 | 先按方向、再在方向仍按住时按 F；接近目标/边界时步行，动作结束立即松键并重新定位 |
| Alt | 启动有效定位后的第 190 秒开始，每隔 190 秒按一次；施法、失焦、暂停和换层时顺延 |
| 空场判断 | 至少两个完整往返均未看到同层候选，且连续无怪至少 3 秒，才允许换层 |
| 上楼 | 步行对齐 X=0.212 → 上＋空格抓梯 → 监测 Y 爬升 → 到 Y=0.130 后松上、空格离梯 → 确认顶层 → 向左瞬移一次 |
| 下楼 | 顶层清空后向左走到 X=0.045，从出口直接走落，不按跳跃；观察 Y 增大，并确认落回底层 |
| 暂停退出 | F8 暂停/恢复，F12 退出，Ctrl+C 退出；失焦、定位丢失、异常时松开脚本按住的键 |

底层边界 X=0.029～0.659、Y=0.759；顶层 X=0.045～0.212、Y=0.130。普通巡逻在边缘内缩 0.055 处掉头，利用射程覆盖边缘；只有主动下楼时才靠近顶层左出口。不会把底层的右边界用于顶层。

**本版不处理中间台阶**，包括 X=0.337 / 0.346 / 0.365 的上移路线。在中层或未确认落地时停止动作。若地面路线被台阶阻断，卡住后掉头，不把未巡视区域算成清空。爬梯卡住或超时会停止换层并停用本次运行的自动换层，不会假定已经爬到顶层。

## Windows 安装和首次校准

在项目根目录的 PowerShell 中执行：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m lionbot --calibrate
.\.venv\Scripts\python.exe -m lionbot --measure-teleport
```

校准会生成 `config.local.json` 和 `calibration/` 下的本机图像，不修改原来的三个脚本。已有配置先备份，再保存；备份和校准文件均被 Git 忽略。

`--calibrate` 引导完成：

1. 框选**小地图坐标区域**。必须与测得 X=.029/.659、Y=.759/.130 时的范围一致，排除标题和按钮。坐标以这个裁剪区域归一化。用底层站立时的 Y≈.759 核对，不能沿用旧地图的 `[146,200,28,236]`。
2. 框选主画面游戏区域，排除聊天栏和 HP/MP 栏。
3. 框选自己固定的角色名牌，点击自己脚底。程序每帧重新定位名牌，支持镜头横向滚动；遮挡或找不到名牌就暂停动作。
4. 框选蓝独角狮的完整头部或身体，再点**同一只怪物的脚底落地位置**。头部模板也需要这个落地偏移，避免攻击上层怪物。建议采集站立、行走、受击至少三种姿态；左右朝向自动镜像，不要截宠物、血条、伤害数字或其他怪物。
5. 在同一平地采集移动前后两个截图，点击角色脚底，并框选有固定地形的背景区域。程序结合小地图位移、角色屏幕位移与背景滚动，估算主画面/归一化 X 比例，并打印 0.086 射程对应的像素。背景配准不可靠时拒绝保存比例。

截图提示后按 Enter，有 3 秒切回游戏并松开按键；选框后 Enter 确认，Esc 取消。采样图像均在本机生成。若只需重测比例：

```powershell
.\.venv\Scripts\python.exe -m lionbot --measure-scale
```

`--measure-teleport` 在底层无遮挡平地手动测量三次「方向键＋F」的位移，记录带安全余量的上限。这里的坐标也是小地图归一化 X。未测量时不会自动猜测瞬移距离；自动上下楼模式要求先完成测量。运行中若位移超过上限，会停用 F，改为步行。

改变分辨率、DPI 缩放、角色名牌或小地图大小后重新校准。窗口可以移动，但不能被其他窗口遮挡或最小化。游戏若屏蔽 pynput 合成输入，本版不能保证按键生效；须先用底层模式现场核对。

## 先观察，再启用按键

```powershell
# 仅显示候选框和建议动作，不发送任何按键。
.\.venv\Scripts\python.exe -m lionbot --observe --show

# 先单独验证底层，禁用自动换层；无瞬移校准也可步行运行。
.\.venv\Scripts\python.exe -m lionbot --floor bottom --run

# 手动站上顶层后，可单独验证顶层，不自动上下楼。
.\.venv\Scripts\python.exe -m lionbot --floor top --run

# 完成校准后，运行底层优先的完整路线。
.\.venv\Scripts\python.exe -m lionbot --run
```

观察窗口放在游戏旁边，不能遮住游戏；点击观察窗口会使游戏失焦。绿框是连续帧确认目标，橙框是待确认候选，紫线表示攻击距离，圆点表示脚底。日志中的 `mobs=确认数/候选数` 仅表示当前主画面，不是全地图怪物数量。

先观察宠物、蓝天、云、受击特效、站立与行走怪物。若误检，重新采集干净模板或在 `config.local.json` 适当提高 `monster_threshold`（默认 .82）；若漏检，优先补充姿态，不要只截小眼睛或直接大幅降低阈值。连续帧确认不能替代好的模板。

也可离线检查与校准相同尺寸的游戏客户区截图：

```powershell
.\.venv\Scripts\python.exe -m lionbot --image frame.png --output debug-output/result.png
```

单张图只显示候选，不伪造连续帧确认。该命令不会发送按键。

## 测试与文件

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

自动测试覆盖：0.9 秒攻击时序、190 秒 Alt、同层/射程筛选、目标消失后不继续盲打、瞬移组合键与松键、空场往返计数、上楼离梯和走落、图像匹配与颜色排除、黄点歧义、镜头补偿，以及离线命令输出。

视觉测试使用合成场景，验证程序链路，**没有证明真实游戏识别准确率**。Windows 实际截图、按键是否被游戏接受、宠物排除效果、上下楼落点，需要用上面的观察和分层模式现场确认。当前云机器没有运行游戏，未做实机验证。

主要文件：`lionbot/brain.py` 决策与路线，`vision.py` 识别和坐标换算，`controls.py` 按键时序，`calibrate.py` 本机校准，`windows.py` 客户区截图，`config.example.json` 地图参数示例。
