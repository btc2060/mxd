# Pig 单层巡逻：沿用上传的 2.py 路线，不做怪物识别

入口 `python.exe -m lionbot.pig`，独立配置 `config.pig.local.json`。garden 入口和配置保持原样。此入口只通过小地图唯一黄点判断位置；不加载怪物、名牌或地形模板。测谎仍单独检查游戏客户区固定标题，命中后松键、报警并等待人工处理，不操作测谎题目。

## 安装和校准

[单机更新包](https://github.com/btc2060/mxd/raw/refs/heads/singlehost-cutnet/downloads/pig-singlehost-update.zip) 解压覆盖到原单机项目根目录。包不包含你的 `.local.json`、校准图片或 WAV。原 requirements.txt 所需依赖保持一致，无需额外安装库。

```powershell
python.exe -m lionbot.pig --setup
python.exe -m lionbot.pig --observe --show
```

setup 只记录游戏客户区大小、框选小地图定位区域；不发送游戏按键。首次可复用同目录 `config.garden.local.json` 的测谎模板、阈值、间隔和声音选择。已有 pig 配置再次 setup 时保留路线、按键等参数。

**小地图归一化坐标依赖框选范围。** 原 `2.py` 使用 `[Y起138,Y止152,X起28,X止188]`，即外窗口截图里的 `(28,138,160,14)` 窄条；新版本截图是游戏客户区，不包含标题栏，不能直接粘贴旧像素框。建议在 setup 中框选与旧程序相同的小地图底层定位窄条，再通过 observe 看 X/Y 是否与旧值相符。若改为整个小地图，尤其 Y 比例会改变，需要调整坑的 `pit_y_threshold`。先只观察、核对边界，确认后再发送按键。

默认归一化路线沿用原脚本：左正常 .25、最左 .16、右 .81；正常左掉头4次后下一次走至最左并重置计数。两个坑 X 为 [.333,.417]、[.651,.736]，Y>=.35 判断在坑内；进坑攻击一次，保持行进方向，步行停滞 .5 秒后空格跳出，跳跃冷却1秒。定点区间 [.745,.805]、[.60,.65]、[.487,.55] 每方向经过打2次；左掉头后也打2次；巡逻中随机补打。平地累计步行受阻约2.33秒会反向，不把施法或定时按键停顿算成走不动。

## 攻击和4组固定定时键

原 `2.py` 用 A 攻击，所以默认 `"attack_key": "a"`。需要 D 时改为 `"attack_key": "d"`。攻击间隔 .3 秒，按住 .08 秒；这些值可修改。

配置内的四组 `timed_keys` 固定按键、固定间隔。例如：

```json
"timed_keys": [
  {"key": "1", "interval_seconds": 300, "hold_seconds": 0.1},
  {"key": "2", "interval_seconds": 600, "hold_seconds": 0.1},
  {"key": "3", "interval_seconds": 0,   "hold_seconds": 0.1},
  {"key": "4", "interval_seconds": 0,   "hold_seconds": 0.1}
]
```

此例每300秒按1，每600秒按2，3和4关闭。**四组默认全部为0，设为0不会启动该按键。** 时间单位秒；启用时至少1秒，按住时间0.02～1秒。只能配置单个按键，使用小写字母、数字、`f1` 等名称；支持 ctrl、shift、space、tab 等。F8/F10/F12 保留为控制热键，不可作为攻击／定时键。不要重复启用同一个定时键。

保留独立 `"alt_interval": 190`：启动时按一次 Alt，此后按间隔执行；此值也可设为0关闭。4组新增键先等满首个间隔再执行。暂停、失焦、黄点丢失和测谎期间均不发送定时键；坑内跳跃阶段暂缓。恢复后到期的每组最多执行一次，不补发暂停期间积累的多次；按实际按下时刻安排下次时间，几个到期键逐一执行。

原脚本的聊天、随机表情不带入这个入口，避免它们与定时键、巡逻抢输入。没有新增回血、换图或自动操作测谎功能。

## 测谎、声音与启动

已有可用测谎模板时直接复用。缺少模板时，在实际窗口可见时采集标题，或用保存的截图：

```powershell
python.exe -m lionbot.pig --calibrate-alert --image "C:/截图/测谎.png"
python.exe -m lionbot.pig --test-alert-sound --alert-voice 4
python.exe -m lionbot.pig --run --alert-voice 4
```

`--alert-voice 4` 使用 `sounds/4.wav`，支持后续任意正整数编号和之前的流式 WAV 兼容处理；原文件不会被转换或覆盖。默认仍为 Beep。也可在配置里保存 `"lie_alert_sound": "4"`。

F8 暂停／恢复。测谎首次命中或截图监控故障时停止所有键并锁定报警；第一次 F8 静音，只有标题连续两帧消失、监控新鲜且游戏前台时，人工 F8 才能恢复。标题消失本身不会自动恢复。F10 保存测谎诊断图和分数，F12 退出；关预览时按预览窗口中的 Q/Esc 可退出。游戏失焦、最小化或黄点缺失时松键，恢复正常监控后继续原方向。

观察模式不发送游戏键、不会执行定时键；声音测试也不操作游戏。运行中修改 JSON 后需重启程序使参数生效。

## 已验证范围

离线测试覆盖左右循环及4次正常／1次最左、进坑攻击与跳跃冷却、定点攻击组、位置丢失松键、4组定时键禁用／到期／不补发、真实按下计时、中断松键，以及主循环报警时禁止所有游戏按键。复用现有窗口筛选、测谎检测与输入守卫。没有在你的 Windows 游戏客户端上实际跑图，首次请先 observe 核对归一化坐标，再 run。
